# [Walkthrough] AIS 포트폴리오 재현 저장소(AIS-portfolio) 구축 및 검증 결과

## 1. 개요 및 사용자 요구사항
본 작업은 `AIS보고서_제출본.pdf` 및 원본 연구 산출물을 기준으로, 대용량 파일(수십 GB의 원본 데이터 로그 및 대형 체크포인트)을 철저히 배제하고 소량의 샘플 데이터로 연구 파이프라인 전체를 원클릭 재현할 수 있는 독립 저장소 `AIS-portfolio`를 구축한 결과입니다.

### 사용자 요구사항
1. `AIS보고서_제출본.pdf` 기준 파이프라인 확정 및 신규 폴더 `AIS-portfolio` 구축
2. 대용량 데이터 파일 배제 및 데이터 폴더 구조/상대 경로 정비
3. 소량 데이터(Mini-Sample)를 통한 전체 파이프라인 동작 확인 및 테스트
4. `readme작성 지침.md` 지침을 철저히 반영한 포트폴리오 스타일 `README.md` 작성
5. 대용량 파일 유입 차단 및 검토 후 한국어 커밋(푸시 대기 상태)

## 3. 검증 및 테스트 결과 (Verification)

### 3.1 엔드투엔드 파이프라인 실행 테스트
```bash
python run_pipeline.py --mode sample
```
- **실행 시간**: **6.35초** (Exit Code 0 완료)
- **전처리**: 3개 경기 6,613개 이벤트 로드 $\rightarrow$ 공격 방향 정규화 $\rightarrow$ 경기 분할(Train 2, Val 1)
- **xAction**: PyTorch MultiTask 모델 학습 $\rightarrow$ Val Macro F1: 0.0951, Acc: 0.6795 $\rightarrow$ `per_match_player_summary.csv` 생성
- **xPass**: 패스 2,525건 추출 $\rightarrow$ XGBoost 학습 $\rightarrow$ Val AUC: 0.7443, LogLoss: 0.4751, Brier: 0.1529 $\rightarrow$ `player_season_xpass.csv` 생성
- **VAEP**: Scores/Concedes MLP 학습 $\rightarrow$ Scores Val AUC: 0.5033, Concedes Val AUC: 0.6680 $\rightarrow$ 선수-경기 및 선수-시즌 단위 VAEP 집계 생성
- **상관관계 분석**: 86개 경기 단위 및 84개 시즌 단위 조인 $\rightarrow$ Spearman/Pearson 상관계수 계산 및 `correlation_summary.json` 저장
